# 5-5  二次型及其标准型

---
> `定义 8`
> 
> 含有 $n$ 个变量 $x _1, x _2, \cdots, x _n$ 的二次函数
> 
> $$f (x _1, x _2, \cdots, x _n) = a _{11} x _1 ^2 + \cdots + 2 a _{n - 1, n} x _{n - 1} x _n$$
> 
> 称为二次型. 可用矩阵记作
> 
> $$
f = \mathbf{x} ^T \mathbf{A} \mathbf{x}
$$
> 其中 $\mathbf{A}$ 为对称矩阵.
