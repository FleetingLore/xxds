# 5-5  二次型及其标准型

---
> `定义 8`
> 
> 含有 $n$ 个变量 $x _1, x _2, \cdots, x _n$ 的二次函数
> 
> $$f (x _1, x _2, \cdots, x _n) = a _{11} x _1 ^2 + \cdots + 2 a _{n - 1, n} x _{n - 1} x _n$$
> 
> 称为二次型. 可用矩阵记作
> 
> $$
f = \mathbf{x} ^T \mathbf{A} \mathbf{x}
$$
> 其中 $\mathbf{A}$ 为对称矩阵.

---
> `定义 9`
> 
> 设 $\mathbf{A}$ 和 $\mathbf{B}$ 是 $n$ 阶矩阵, 若有可逆矩阵 $\mathbf{C}$, 使 $\mathbf{B} = \mathbf{C} ^T \mathbf{A} \mathbf{C}$, 则称矩阵 $\mathbf{A}$ 与 $\mathbf{B}$ 合同.

---
> `定理 6`
> 
> 任给二次型 $f = \sum _{i, j = 1} ^n a _{ij} = x_i x_j (a _{i j} = a _{j i})$, 总有正交变换 $\mathbf{x} = \mathbf{P} \mathbf{y}$ 使 $f$ 化为标准形
> 
> $$f = \lambda _1 y _1 ^2 + \lambda _2 y _2 ^2 + \cdots + \lambda _n y _n ^2$$
> 
> 其中 $\lambda _1, \lambda _2, \cdots, \lambda _n$ 是 $f$ 的矩阵 $\mathbf{A} = (a _{i j})$ 的特征值.

---
> 推论
> 
> 任给 $n$ 元二次型 $f (\mathbf{x}) = \mathbf{x} ^T \mathbf{A} \mathbf{x}\ (\mathbf{A} ^T)$, 总有可逆变换 $\mathbf{x} = \mathbf{C} \mathbf{z}$, 使 $f (\mathbf{C} \mathbf{z})$ 为规范形.
